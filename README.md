# Hangman Game (Python)

A simple command-line Hangman game built using Python as part of my programming learning journey.

---

##  How the game works

The player tries to guess a hidden word one letter at a time.
Each incorrect guess brings the player closer to losing the game.
Artwork to show the lives taken is presented, there is a total of 6 lives.
